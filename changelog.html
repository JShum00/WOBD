Changelog

What changed in each WOBD release, newest first.

v1.72 October 22, 2026

  • Every report graph now comes from the recording itself. The PT Cruiser and Highlander graphs were redrawn from their CSVs with one shared layout, so they're accurate and comparable. Times when the engine was off are shaded and labelled instead of drawn across.

v1.71 October 22, 2026

  • Exports say which WOBD made them. CSV recordings start with a # WOBD v… line, and adapter traffic logs and DTC reports name the version too. Replay shows it in the file summary.
  • Report pages read the version from the files. The tested adapters table and each report page show it, and a version typed in by hand marks older tests (the PT Cruiser is 1.0, the Highlander 1.51).
  • Recordings saved from this version can't be opened by older WOBD versions because of the new first line.

v1.7 October 22, 2026

  • Clearer connection problems. Bob now tells apart a missing adapter, an adapter that stopped answering, a car that isn't answering, a data-line error, and a reply WOBD couldn't read, and shows what the adapter itself said (like "CAN ERROR").
  • Protocol hints. If you forced a protocol and it fails, Bob names it and suggests going back to automatic first. With your car's year, make, and model filled in, there's an optional search link for its protocol.
  • Fuel tank level appears as a live gauge on cars that report it (PID 0x2F).
  • The development banner can be closed with the ✕. It comes back after the next release.

v1.6 October 22, 2026

  • Trouble code pages. Every code Bob has hand-written notes for now has its own page, like P0340, with urgency, common causes, and what to tell your mechanic. They're linked from Code Search so search engines and people can find them.
  • Home page intro and FAQ in plain HTML, plus a sitemap and search-engine hints.
  • New live data decoders: wideband oxygen sensors (PIDs 0x24 and 0x34) and absolute EVAP vapor pressure (0x53). Parameters WOBD can't name yet are now labelled "Unnamed parameter" instead of "Not a standard PID".
  • Raw recording bytes. Recordings now keep each reply's raw bytes, the service, and the responding ECU, so readings can be decoded later when a decoder is added. Older recordings still replay.
  • Optional raw capture of undecoded parameters, off by default and behind a confirmation dialog. It samples sparingly so normal gauges keep priority.
  • Tested adapters reorganized by adapter, make, year, and model. Added a 2010 Toyota Highlander test with a live data replay, graph, and the adapter's traffic log.
  • (i) popovers explain why a feature wasn't tested, such as clearing codes when there were none to clear.
  • Changelog page (this one). The version in the footer links here.

v1.51 October 21, 2026

  • New WOBD logo in the header and a new favicon.

v1.5 October 21, 2026

  • Updated navigation and demo layout.
  • Replay loads CSV recordings in pieces and accepts files up to 128 MiB.
  • Replay charts are simplified for display while keeping every original reading for playback and hover.

v1.4 October 20, 2026

  • Advanced diagnostics, with a tab per module when several modules answer a scan.
  • Fixed status reporting to combine results from every responding module.
  • Fixed replies on older J1850 and ISO headered protocols that included a stray checksum byte.

v1.3 October 3, 2026

  • Choose a connection protocol yourself when automatic detection fails, with fuller troubleshooting help in the guide.
  • Car simulator for trying any year, make, and model without an adapter.
  • Recording, replay, and supported-parameter tests added.

v1.2 October 2, 2026

  • Tested Adapters page with personal results for each adapter.
  • Connection info panel showing adapter details and clearer errors.
  • Optional year, make, and model for more precise code searches.
