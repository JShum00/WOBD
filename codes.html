Trouble code search

Type a code from your check engine light, like P0601, and Bob will explain it. This works offline and doesn't need an adapter.

The offline list covers the standard (SAE generic) codes for the engine and transmission (P0, P2, P34), body (B0), chassis (C0), and network (U0, U3). Codes starting with P1, or P30-P33, are defined by each car maker, so Bob won't guess at them.
